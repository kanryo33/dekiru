# 日本語単語カード（四语单词卡）

覆盖《できる日本語》系列（初級 / 初中級 / 中級）与《文法Buddy JLPT N3》两套教材的「日・英・中・尼泊尔语」四语单词卡，供课堂上投影使用。

- **在线使用**：<https://kanryo33.github.io/dekiru/>
- **本地使用**：下载后双击 `index.html` 即可（无需服务器）

## 功能特性

- 两个下拉菜单：先选「等级」（初級 / 初中級 / 中級），再选「课程」
- 卡片翻转显示，支持两种模式：
  1. 漢字 → 読み・意味
  2. 英・中・ネパール語 → 日本語
- 大字大卡，适合投影（透视已调平，翻转无位移）
- 支持键盘操作（Space 翻面、← / → 切换词卡）

## 数据结构

| 等级 | 文件 | 数据规模 |
|---|---|---|
| 初級 | `app_words.json` | 15 课，744 词 |
| 初中級 | `chuukyuu_payload.json` | 15 课，1030 词 |
| 中級 | `med_trilingual.json` | 20 课，2288 词 |
| N3 文法Buddy | `buddy_N3_词汇表_中日英尼.json` | 14 课，563 词 |

- **初級 / 初中級** 每条：`{ kanji, kana, eng, cn, ne }`
- **中級** 每条：`{ lesson, no, kanji, kana, en, cn, ne, src }`，`src` 标记官方来源 / 补译
- 中級有 38 词在官方尼语 PDF 中不存在，标注为「（公式リストになし）」
